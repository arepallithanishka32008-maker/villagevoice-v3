# VillageVoice - Kaza, Movva Mandal  (Version 16, final)
START (Windows): extract to a NEW folder, double-click phone.bat (laptop + phone on the same Wi-Fi) or start.bat (laptop only), then open http://127.0.0.1:5000
Keep your data: copy your old villagevoice.db and keys.bat into the new folder before the first run.
Logins: /admin (coordinator) and /officer/login (Karyadarsi). Settings and keys: keys.bat. Telugu words: i18n.py. Villages and map: config.py.
The footer of every page shows the version number.
